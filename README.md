# 3D 推金幣射擊機

直式（9:16）網頁遊戲，手機觸控與電腦滑鼠皆可玩；電腦橫螢幕會置中顯示直式畫面。純前端（Three.js + cannon-es，由 CDN 載入）。用任何靜態伺服器開啟 `index.html` 即可：

```
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

## 玩法
- 「投幣 +10」（或空白鍵）取得 10 發金幣子彈。
- 在上方畫面瞄準：滑鼠移動／手指點按；按住蓄力、放開射擊，蓄力越久射得越遠（近排 → 中排 → 遠排）。
- 射中吊掛道具或繩子有機率斷繩；金幣越多越難斷，偶爾「爆擊」大幅提升機率。
- 斷繩：獲得道具標示的金幣（滾入下方金幣池）＋ 1 顆金蛋。集滿 3 顆金蛋開獎：隨機金幣(≤50)／落空／紅球／轉盤機會，各 25%。
- 轉盤：10 格（10/20/50/100/200 金幣、2 鑽石、2 飛鏢、1 魔術帽）。集滿 3 個同種符號進入小遊戲：鑽石→連連看、飛鏢→飛鏢、魔術帽→魔術帽。
- 飛過畫面的「免費子彈」（10 秒不耗子彈）與「威力子彈」（50 秒斷繩機率提升）圖示可以射擊取得。
- 金幣被推出前緣：每枚 1 張彩券；紅球 20 張。滑鼠移到下方彩券機可看目前彩券數。

## 參數
- `?lowfx=1`：關閉陰影（低階裝置用）
- `?debug=1`：顯示除錯面板（快捷鍵 1/2/3 小遊戲、E 金蛋、O 開蛋、W 轉盤、C +600 金幣、F/P 道具、B 斷繩）
